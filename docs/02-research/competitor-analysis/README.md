# 竞品分析工作区

## 目标

识别真实健康类 App 的优势、不足与未满足需求，为问卷设计提供可核实的背景，并在研究完成后帮助确定首轮基础功能。

## 已确定的流程

1. 使用 AI 联网搜索真实 App、公开功能说明和用户反馈。
2. 由小组成员人工打开来源或商店页面核对；不能直接引用 AI 生成但未验证的“竞品缺点”。
3. 对每个竞品记录来源链接、访问日期、平台和核对状态。
4. 按饮食、活动、作息、主动支持、通知控制、隐私等维度比较。
5. 综合出研究机会与候选功能，而不是按功能数量堆砌产品。

## 质量检查

- [ ] 每个结论可追溯到公开来源。
- [ ] 区分官方宣传、第三方评测和用户评论。
- [ ] 不将某个 App 的功能缺失直接视为用户需求。
- [ ] 记录平台、地区、版本和访问日期，因为功能可能变化。
- [ ] 对健康建议的可靠性、隐私和伦理风险进行单独判断。
