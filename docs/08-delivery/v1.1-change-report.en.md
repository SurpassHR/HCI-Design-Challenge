## 1. Summary

v1.1 is an incremental rebuild using the new Figma file as visual source of truth. It expands the v1.0 seven-screen prototype to eight screens (adding Me), introduces global large text, F02 dish search and F01 custom avoidances, and rebuilds colours, cards, navigation and hierarchy. Domain data, Mock Repositories, route structure and the reserved /api/v1 contract remain compatible.

The release also corrects a conflict between the design source and engineering standards: Figma emoji icons are treated as a design defect and replaced with Lucide + FoodGlyph vector icons. The Figma status bar and phone frame are not implemented in the web app.

## 2. UI/UX changes

### 2.1 Global visuals

- New colours: bg #FFF7EC, surface #FFFFFF, ink #1E1A3C, muted #6E6A8A, line #EEE6DA, purple #7B5CFF, orange #FF8A3D, pink #FF5C8A, green #22C27A, yellow #FFC83D and blue #38B6FF.
- Card radii increase to 18–26px; the tab bar becomes a white floating bar with purple active states and a coral/orange scan FAB.
- The content column tightens to 390px; no simulated status bar, signal/battery or phone frame.
- Vector icons remain mandatory; no emoji; decorative icons are aria-hidden.

## 3. Interaction changes

- F02 adds local real-time search over names, tags and keywords; Try Tofu/Sushi fills the query; empty results are recoverable.
- F01 adds + Add: a local sheet accepts any ingredient/allergen, de-duplicates and saves with Continue. Edit mode returns to /me; onboarding does not invent missing steps.
- Me adds Large text: global semantic tokens (about +2px), persisted under nutripal.v1.display; pages scroll instead of clipping.
- F03b promotes Share list over Order for delivery; delivery remains a secondary demo action with no order or payment.
- F06 renames the primary CTA to Log to Dinner; portion calculation and return Home are unchanged.
- Me retains language, today’s targets, preference summary, Preview a nudge, Nudges and privacy. The two Figma setting rows replace old headings without dropping information.
- F03/F04/F05 date, swap, regenerate, Cook this, Other ideas, Not now, snooze, frequency and feedback behaviour is retained.

## 6. Data and compatibility

- nutripal.v1.profile and nutripal.v1.language are retained; existing data is not cleared.
- nutripal.v1.display is new and defaults to textSize=default.
- Legacy No preference values are no longer rendered as chips; an empty selection is no preference.
- Custom avoidances use the existing avoidAllergens string array, so no migration is needed.
- No real camera, location, notification, recipe or image-recognition capability is added.

## 7. Verification and known deviations

- npm test: 13 passing.
- npm run lint: passing.
- npm run build: passing.
- Browser walkthrough at 390 × 844: all eight screens work in default and large text; see the [Figma/implementation comparison](../../design/exports/2026-11-25-nutripal-v2/implementation/comparison-gallery.png).
- Large-text node audit: all 261 text nodes across eight routes grow by 2px; no unscaled text remains; inputs remain 16/17px.

Intentional deviations:

- Figma emoji are replaced with vector icons.
- Figma status bar and phone frame are not implemented.
- Me is longer than Figma to retain all v1.0 content and scrolls.
- Clipping in fixed large-text Figma frames is not a requirement.
- F03b Feta starts checked to match the archive demo state; the total remains four items.

## 8. Conclusion

v1.1 achieves the goal of “new Figma structure + retained v1.0 functions + accessibility and search enhancements”. The next iteration should focus on real user testing, permission flows and Provider integration rather than further visual tuning.

## 9. Post-release increments (2026-11-26)

- Mobile input-focus zoom is fixed; page pinch zoom is disabled by requirement.
- Large text now covers all 261 text nodes, each growing by 2px.
- F02 search uses a Supabase-compatible mock with 91 recipes (86 TheMealDB + 5 built-in), supporting English/Chinese, multi-word, closest-match, suggestions and a detail sheet.
