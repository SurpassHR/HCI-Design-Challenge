# 交付材料

> 源文档没有定义最终报告、展示或代码提交的具体格式。此目录仅预留交付索引。

## 建议目录

| 目录 | 内容 |
| --- | --- |
| `report/` | 最终报告、图表、参考文献与附录 |
| `presentation/` | 展示稿、讲稿、演示媒体 |
| `evidence/` | 问卷摘要、竞品证据、测试结果等可复现材料 |

## 交付前检查（待补充）

- [ ] 问题、研究发现、设计决策和技术实现之间可追溯。
- [ ] 引文、数据与图片来源完整。
- [ ] 用户数据已去标识化并获得使用许可。
- [ ] Figma 原型可点击、无死链，并提供访问方式。
- [ ] 报告与展示中的功能范围一致，不夸大技术实现。
- [ ] 仓库 README 与最终交付状态同步。
