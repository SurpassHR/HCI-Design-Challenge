# NutriPal v1.1 版本变更报告（对比 v1.0）

**语言：[中文](v1.1-change-report.md) | [English](v1.1-change-report.en.md)**

> - 对比基线：v1.0（tag 指向 1.0.0 发布提交）
> - 当前版本：v1.1 / 1.1.0
> - 报告日期：2026-11-26
> - 设计基线：[2026-11-25 Figma v2 归档](../../design/exports/2026-11-25-nutripal-v2/README.md)
> - 完整差异：git diff v1.0..v1.1

## 1. 摘要

v1.1 是一次以新 Figma 文件为视觉事实源的增量重构。它把 v1.0 的 7 屏原型扩展为 8 屏（新增 Me 设置页），新增全局大字号、F02 菜品搜索和 F01 自定义忌口，并重做颜色、卡片、底部导航与页面层级。领域数据、Mock Repository、路由主体和 /api/v1 预留契约保持兼容。

本轮同时纠正了设计源与工程规范的冲突：Figma 中的 emoji 图标被视为设计失误，最终实现全部使用 Lucide + FoodGlyph 矢量图标；Figma 状态栏和手机圆角框不进入 Web App。

## 2. UI/UX 变更

### 2.1 全局视觉

- 颜色改为 bg #FFF7EC、surface #FFFFFF、ink #1E1A3C、muted #6E6A8A、line #EEE6DA、purple #7B5CFF、orange #FF8A3D、pink #FF5C8A、green #22C27A、yellow #FFC83D、blue #38B6FF。
- 卡片圆角提升到 18–26px，底部导航改为白色悬浮条、紫色激活态与珊瑚/橙色扫描 FAB。
- 内容列收紧到 390px；不显示模拟状态栏、信号/电池或手机边框。
- 图标继续使用矢量系统，不使用 emoji；所有装饰性图标保持 aria-hidden。

### 2.2 逐屏变化

| 页面 | v1.0 | v1.1 |
| --- | --- | --- |

| F02 | 深色营养摘要、无搜索 | 紫粉渐变摘要、搜索框、Try 芯片、空状态、新标题层级与卡片 |

## 3. 交互逻辑变更

- F02 新增本地实时搜索：匹配菜名、标签与关键词；Try Tofu/Sushi 可一键填入；无结果显示空状态并可显示全部菜品。
- F01 新增 + Add：本地 Sheet 输入任意食材/过敏原，去重后随 Continue 保存；编辑模式返回 /me，首次引导不伪造既有步骤。
- Me 新增 Large text：全局切换语义字号 token（约 +2px），写入 nutripal.v1.display，刷新后保留；所有页面滚动而不裁切。
- F03b 主操作从 Order for delivery 改为 Share list；配送保留为次级演示按钮，不创建订单或支付。
- F06 主 CTA 从 Add to today's log 改为 Log to Dinner，份量计算与返回 Home 行为不变。
- Me 保留语言切换、今日目标、偏好摘要、Preview a nudge、Nudges 入口和隐私说明；Figma 两项设置行替代旧标题但信息不丢失。
- F03/F04/F05 的日期、换餐、重生成、Cook this、Other ideas、Not now、Snooze、频率和反馈行为保持。

## 4. 软件架构变更

| 层级 | v1.0 | v1.1 |
| --- | --- | --- |
| 显示偏好 | 无 | 新增 DisplayPreferences 领域类型、localStorage Repository、Context/Provider |
| 样式 | 单层 styles.css | styles.css + tokens.css + components.css + v11.css 分层 |
| 共享 UI | 页面内样式与少量组件 | 新增 Chip、CuisineTile、Toggle、SegmentedControl、SettingsRow、Sheet |
| 状态 | Profile + Language | Profile + Language + DisplayPreferences |
| 数据/API | Mock Repository + /api/v1 预留 | 保留；新增本地显示偏好键和只读 91 道菜谱目录 |
| 测试 | 9 条验收 | 13 条验收，覆盖 Mock 菜谱搜索、大字号 CSS 回归、自定义忌口与新 fixture |

不新增运行时依赖，不修改 HTTP 接口、Profile schema 或路由路径。

## 6. 数据与兼容性

- 保留 nutripal.v1.profile 和 nutripal.v1.language，不清空既有用户数据。
- 新增 nutripal.v1.display，默认 textSize=default。
- 旧数据中的 No preference 不再显示为芯片；空选择即无偏好。
- 自定义忌口直接存入既有 avoidAllergens 字符串数组，无需迁移。
- 未新增真实相机、定位、通知、食谱或图像识别能力。

## 7. 验证与已知偏差

- npm test：13 条通过。
- npm run lint：通过。
- npm run build：通过。
- 390 × 844 浏览器走查：8 个页面默认/大字号均可用；见 [Figma/实现对照图](../../design/exports/2026-11-25-nutripal-v2/implementation/comparison-gallery.png)。
- 大字号逐节点审计：8 个路由共 261 个文本节点全部 +2px，无未放大文本；输入框保持 16/17px。

有意偏差：

- Figma emoji 不进入实现，替换为矢量图标。
- Figma 状态栏/手机框不进入实现。
- Me 比 Figma 更长，以容纳 v1.0 全部内容并允许滚动。
- Figma 大字号固定画框中的裁切不作为实现要求。
- F03b Feta 初始勾选用于匹配归档演示态，总数仍为 4 项。

## 8. 结论

v1.1 完成了“新 Figma 结构 + v1.0 功能保留 + 无障碍与搜索增强”的目标。下一次迭代可聚焦真实用户测试、权限流程和 Provider 接入，而不是继续视觉微调。

## 9. 发布后增量（2026-11-26）

- 移动端输入聚焦缩放已修复；页面双指缩放按要求关闭。
- 大字号从仅 token 文本扩展到全站 261 个文本节点，全部 +2px。
- F02 搜索升级为 Supabase 兼容 Mock：91 道菜谱（86 条 TheMealDB + 5 条内置），支持中英文、多词、相似匹配、空结果建议和详情 Sheet。
