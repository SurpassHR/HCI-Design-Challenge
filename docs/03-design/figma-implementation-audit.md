## 4. 全局设计解释

- **图标处理**：撤销旧的禁用 emoji 决定；F01 使用 Figma emoji，F02–F07/F03b 使用 Figma 导出的 SVG 资源（public/figma-icons），不再自绘近似图标。
- **设备 chrome**：不显示状态栏、信号/电池或圆角手机框；Web 内容列以 390px 为设计基准，并随视口流式扩展至 1200px。
- **大字号**：默认/大字号使用同一组件树，通过语义字号 token 切换；固定画框中的裁切不视为实现要求。
- **大字号完整性**：v1.1 的 8 个路由共 261 个直接文本节点全部增加 2px；F07 新增节点同样使用语义字号 token，无遗漏。
- **Me 页长度**：为保留 v1.0 功能，Me 比 Figma 更长，需要滚动；这是有意差异。
- **F03b 初始状态**：Feta 初始勾选，用于匹配归档演示态；总数仍显示 4 项。
